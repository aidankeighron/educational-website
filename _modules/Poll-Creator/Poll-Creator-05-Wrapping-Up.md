### Congratulations!

You have finished the main project. Over the course of this project hopefully you learned how to...

- use Google Firebase products
- develop mobile software using react native
- code using React useStates and useEffects
- add and retrieve data from a NoSQL database

These are industry standard tools that should give you a leg up when building a resume and interviewing. Most importantly, they lay the foundation for you to go and do further projects!

Rather than starting again from scratch, there's a number of cool expansion ideas you could implement on top of the main project. These range in difficulty so choose one that will challenge you to learn!

***
**Expanding ideas:**
- Add the ability for an admin to have more than one live poll
- Add in the "login with Google" or other providers from Firebase Auth (you can toggle these in the firebase console)
- Create a "resubmit" button if a user wants to change their vote
- Have an AI model explain the poll results to the admin


As always, if you have your own great ideas make sure to implement them! We'd love to see what creative features you add to the base project!
