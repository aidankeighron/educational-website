### About the Project

In this project you will learn how to use react native, a common framework for developing mobile applications that function on both android and iOS operating systems. Along the way you will also learn to incorporate Google Firebase features such as the Firestore database and Firebase auth.

**What you will learn**
- How to develop in react native using Expo Go
- How to use useState and useEffect in React
- How to connect to Google Firebase auth and db

**What you should already know**
- JavaScript
- How to use Git/GitHub
